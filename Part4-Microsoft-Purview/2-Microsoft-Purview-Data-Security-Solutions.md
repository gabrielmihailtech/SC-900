# Microsoft Purview Data Security Solutions

## Information Protection

Microsoft Purview Information Protection helps organizations discover, classify and protect sensitive data.

Classification methods include:

- Sensitive information types
- Trainable classifiers
- Exact Data Match
- Content and Activity explorers

---

## Sensitivity Labels

Sensitivity labels classify and protect documents, emails and other data.

Labels can apply:

- Encryption
- Access restrictions
- Headers, footers and watermarks
- Content markings

The protection remains with the data when it is shared or moved.

---

## Data Loss Prevention

Microsoft Purview Data Loss Prevention (DLP) helps prevent sensitive information from being shared or used incorrectly.

DLP policies can:

- Detect sensitive data
- Warn users about risky actions
- Block inappropriate sharing
- Record incidents for investigation

---

## Insider Risk Management

Insider Risk Management detects potentially harmful activities performed by users inside an organization.

Examples:

- Data theft
- Security policy violations
- Inappropriate data sharing
- Data leaks by departing employees

It uses policies, indicators and alerts while supporting user privacy.

---

## Adaptive Protection

Adaptive Protection combines Insider Risk Management with DLP.

It dynamically changes protection controls based on a user’s current risk level.

Higher-risk users can receive stronger DLP restrictions.

---

## Data Security Posture Management

Data Security Posture Management provides unified visibility into sensitive data and security risks.

It helps organizations:

- Discover sensitive data
- Identify risky activity
- Prioritize security risks
- Improve data protection controls

---

## Data Security Investigations

Microsoft Purview Data Security Investigations helps security teams investigate data-related incidents.

It provides relevant data and context to understand what happened, what information was affected and which users were involved.

---

## Key Takeaways

- Information Protection discovers and classifies sensitive data.
- Sensitivity labels apply persistent protection to data.
- DLP prevents inappropriate sharing of sensitive information.
- Insider Risk Management detects risky internal activity.
- Adaptive Protection adjusts controls according to user risk.
- Data Security Posture Management provides visibility into data risks.
- Data Security Investigations supports investigation of data security incidents.
