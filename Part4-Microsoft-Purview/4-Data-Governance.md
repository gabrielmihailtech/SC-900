# Microsoft Purview Data Governance Solutions

## Data Governance

Data governance is the process of managing organizational data so that it remains:

- Discoverable
- Secure
- Reliable
- Accessible to authorized users
- Compliant with organizational and regulatory requirements

It defines responsibilities and establishes policies for managing data throughout its lifecycle.

---

## Data Governance Roles

Data governance requires collaboration between different roles.

Common responsibilities include:

- Defining data policies
- Managing data access
- Maintaining data quality
- Protecting sensitive information
- Ensuring regulatory compliance

---

## Microsoft Purview Data Map

Microsoft Purview Data Map creates a foundation for data governance by scanning and capturing metadata.

It can discover data across:

- On-premises environments
- Hybrid environments
- Multicloud environments

The Data Map helps organizations understand where their data is located and how it is organized.

---

## Microsoft Purview Unified Catalog

Unified Catalog uses metadata from the Data Map to help organizations find, understand, and manage their data.

Its capabilities include:

- Data discovery
- Data curation
- Access management
- Data quality management
- Data health monitoring
- Governance management

---

## Data Map vs Unified Catalog

- **Data Map** discovers data and collects its metadata.
- **Unified Catalog** uses that metadata to support discovery, governance, access, and data quality.

---

## Key Takeaways

- Data governance establishes control and responsibility over organizational data.
- Microsoft Purview Data Map scans data sources and captures metadata.
- Data Map supports on-premises, hybrid, and multicloud environments.
- Unified Catalog builds governance capabilities on top of the Data Map.
- Unified Catalog supports data discovery, access, quality, and health management.
