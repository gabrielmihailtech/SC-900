# Microsoft Defender XDR

## Overview

Microsoft Defender XDR is an integrated security platform that protects identities, endpoints, applications, email and cloud services.

It combines security information from multiple Microsoft Defender products to detect and respond to sophisticated attacks.

---

## Microsoft Defender Services

### Defender for Office 365

Protects email and collaboration services against phishing, malicious links, attachments and other threats.

### Defender for Endpoint

Protects computers, servers and mobile devices against endpoint threats.

### Defender for Cloud Apps

Provides visibility and control over cloud application usage and related risks.

### Defender for Identity

Detects identity-based threats involving on-premises Active Directory.

### Defender Vulnerability Management

Identifies, assesses and prioritizes vulnerabilities and security weaknesses.

### Defender Threat Intelligence

Provides information about threat actors, attack methods and malicious infrastructure.

---

## Integrated Protection

Microsoft Defender XDR provides cross-product capabilities such as:

- Automatic threat response
- Automatic attack disruption
- Self-healing for compromised assets
- Unified incident investigation
- Correlation of alerts from different services

---

## Microsoft Defender Portal

The Microsoft Defender portal provides a unified platform for security operations.

Analysts can use it to:

- View and investigate incidents
- Manage alerts
- Hunt for threats
- Review security recommendations
- Perform response actions

---

## Security Copilot Integration

Microsoft Security Copilot integrates with Defender XDR through standalone and embedded experiences.

AI agents such as the Phishing Triage Agent and Threat Intelligence Briefing Agent help automate security tasks.

---

## Key Takeaways

- Defender XDR combines multiple Microsoft Defender services.
- It protects identities, endpoints, email, applications and cloud resources.
- Alerts from different products are correlated into unified incidents.
- Automatic attack disruption can stop attacks across multiple systems.
- The Defender portal provides centralized security investigation and response.
- Security Copilot and AI agents help analysts work more efficiently.
