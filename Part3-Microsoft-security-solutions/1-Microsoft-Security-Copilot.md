# Microsoft Security Copilot

## Overview

Microsoft Security Copilot is an AI-powered, cloud-based security analysis tool.

It helps security teams:

- Investigate threats
- Respond to incidents faster
- Assess security risks
- Manage security posture
- Generate actionable reports

---

## Integration

Security Copilot integrates with Microsoft products such as:

- Microsoft Defender XDR
- Microsoft Sentinel

It can also connect to non-Microsoft solutions through plugins.

---

## Prompts

Analysts interact with Security Copilot using natural language prompts.

An effective prompt should contain:

- **Goal** – what you want Copilot to do
- **Context** – relevant background information
- **Expectations** – the required response format
- **Source** – the data or plugins it should use

---

## Prompt Processing

Security Copilot:

1. Interprets the prompt.
2. Uses connected security data and plugins.
3. Processes the request using AI models.
4. Generates a response for the analyst.

The process log shows how the response was generated and which sources were used.

---

## Security and Privacy

Security Copilot protects organizational data and provides transparency through its process log.

This allows analysts to verify the sources and validity of generated information.

---

## Key Takeaways

- Security Copilot assists analysts using generative AI.
- It supports threat investigation, incident response and reporting.
- Analysts communicate with it through natural language prompts.
- Good prompts include a goal, context, expectations and source.
- Plugins connect Copilot to Microsoft and third-party security products.
- The process log helps analysts verify generated responses.
