# Microsoft Defender for Cloud

## Overview

Microsoft Defender for Cloud helps organizations improve their cloud security posture and protect cloud workloads against threats.

It supports Azure, hybrid and multicloud environments.

---

## Core Pillars

### DevSecOps

Integrates security into the software development lifecycle.

It helps identify security issues in:

- Source code
- Infrastructure as code
- Development pipelines
- Cloud configurations

### Cloud Security Posture Management (CSPM)

CSPM identifies security weaknesses and provides recommendations to improve the security posture.

It includes:

- Security assessments
- Risk-based recommendations
- Attack path analysis
- Regulatory compliance monitoring

### Cloud Workload Protection Platform (CWPP)

CWPP provides threat protection for cloud workloads such as:

- Virtual machines
- Containers
- Databases
- Storage
- Servers

Protection is enabled through Microsoft Defender plans.

---

## Security Policies and Standards

Security policies define the requirements that cloud resources should follow.

Security standards group security controls based on frameworks and organizational requirements.

Defender for Cloud evaluates resources and generates recommendations when security weaknesses or misconfigurations are detected.

---

## AI Security

Defender for Cloud protects generative AI workloads through:

- AI security posture management
- AI threat protection
- Risk and vulnerability detection
- Security recommendations

---

## Key Takeaways

- Defender for Cloud improves cloud security posture and protects workloads.
- Its three pillars are DevSecOps, CSPM and CWPP.
- CSPM identifies risks, misconfigurations and attack paths.
- CWPP protects cloud workloads through Microsoft Defender plans.
- Security policies and standards generate recommendations.
- DevSecOps introduces security into development processes.
- AI security capabilities protect generative AI workloads.
