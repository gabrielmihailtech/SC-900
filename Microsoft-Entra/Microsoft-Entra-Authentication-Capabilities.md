# Microsoft Entra Authentication Capabilities

## Authentication Methods

Microsoft Entra ID supports several authentication methods:

- Passwords
- Phone calls and SMS
- OATH tokens
- Windows Hello for Business
- Passkeys (FIDO2)
- Microsoft Authenticator
- Certificate-based authentication

Passwordless and phishing-resistant methods provide stronger protection, especially against phishing and AI-driven attacks.

---

## Multifactor Authentication (MFA)

MFA requires two or more verification factors:

- Something you know — password or PIN
- Something you have — phone or security key
- Something you are — fingerprint or facial recognition

This provides additional protection if one authentication factor is compromised.

---

## Self-Service Password Reset (SSPR)

SSPR allows users to reset their own passwords without contacting IT support.

Benefits:

- Faster account recovery
- Reduced IT workload and costs
- Improved user productivity

Microsoft Entra also provides AI-powered account recovery for users who lose access to all registered authentication methods.

---

## Password Protection

Microsoft Entra Password Protection blocks weak and commonly used passwords through:

- Global banned password lists
- Custom banned password lists
- Password normalization
- Fuzzy matching for common variations

---

## Key Takeaways

- Microsoft Entra ID supports password, passwordless and certificate-based authentication.
- Phishing-resistant methods offer the strongest protection.
- MFA requires multiple verification factors.
- SSPR allows users to reset their own passwords.
- Password Protection blocks weak passwords and their variations.
