Microsoft Entra Identity Governance and Protection

## Identity Governance

Microsoft Entra ID Governance helps organizations manage and control identities throughout their lifecycle.

Main capabilities:

- Identity lifecycle management
- Access reviews
- Entitlement management
- Privileged Identity Management (PIM)

These capabilities support Zero Trust and the principle of least privilege.

---

## Access Reviews

Access reviews regularly verify whether users still require access to:

- Applications
- Groups
- Teams
- Privileged roles

Unnecessary access can then be removed.

---

## Entitlement Management

Entitlement management automates how users request, receive and lose access to organizational resources.

Resources can be grouped into access packages containing applications, groups and sites.

---

## Privileged Identity Management (PIM)

PIM controls access to privileged roles.

It provides:

- Just-in-time access
- Time-limited role activation
- Approval requirements
- MFA requirements
- Activity monitoring

---

## Identity Protection

Microsoft Entra ID Protection detects, investigates and remediates identity-related risks.

Examples:

- Risky users
- Risky sign-ins
- Compromised credentials

---

## Microsoft Entra Verified ID

Verified ID enables privacy-protected verification of digital credentials.

It can also support high-assurance account recovery.

---

## AI Agent Identity Governance

Microsoft Entra Agent ID extends identity governance controls to AI agent identities.

It helps organizations manage and control how AI agents access resources.

---

## Microsoft Security Copilot Integration

Microsoft Entra integrates with Microsoft Security Copilot through:

- Standalone experiences
- Embedded experiences
- Specialized security agents

This helps security teams investigate identity risks and manage security operations.

---

## Key Takeaways

- Identity Governance manages identities and access throughout their lifecycle.
- Access reviews remove unnecessary access.
- Entitlement management automates access requests and assignments.
- PIM provides controlled, temporary privileged access.
- Identity Protection detects and remediates identity risks.
- Verified ID provides secure and privacy-protected credential verification.
- Entra Agent ID applies governance controls to AI agents.
- Security Copilot assists with identity security and investigations.
