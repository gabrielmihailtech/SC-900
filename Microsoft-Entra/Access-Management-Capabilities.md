# Microsoft Entra Access Management

## Conditional Access

Conditional Access is Microsoft’s Zero Trust policy engine.

It uses signals such as:

- User identity
- Device
- Location
- Application
- Risk level

Based on these signals, Microsoft Entra ID decides whether to allow, block or restrict access.

Authentication strengths can require specific authentication methods for sensitive resources.

---

## Global Secure Access

Global Secure Access provides identity-aware network security through:

- Microsoft Entra Internet Access
- Microsoft Entra Internet Access for Microsoft Services
- Microsoft Entra Private Access

It protects access to the internet, Microsoft 365 and private corporate resources.

---

## Role-Based Access Control (RBAC)

Microsoft Entra ID uses built-in and custom roles to control administrative permissions.

- **Microsoft Entra RBAC** controls access to identity-related resources.
- **Azure RBAC** controls access to Azure resources.

---

## Key Takeaways

- Conditional Access makes access decisions using identity, device, location and risk signals.
- Authentication strengths require approved authentication methods.
- Global Secure Access protects internet, Microsoft 365 and private access.
- Entra roles determine administrative permissions.
- Entra RBAC manages identities; Azure RBAC manages Azure resources.
