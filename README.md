# Microsoft SC-900: Security, Compliance and Identity Fundamentals

## Overview

This repository contains my study notes, summaries and learning progress for Microsoft's SC-900: Security, Compliance and Identity Fundamentals certification.

The goal of this course is to build a strong foundation in cybersecurity, identity management, cloud security, compliance and Microsoft security solutions.

## Topics Covered

- Security Concepts
- Shared Responsibility Model
- Defense in Depth
- Zero Trust
- CIA Triad
- Encryption and Hashing
- Governance, Risk and Compliance (GRC)
- Microsoft Entra ID
- Authentication and Authorization
- Multi-Factor Authentication (MFA)
- Microsoft Defender
- Microsoft Sentinel
- Microsoft Purview
- Compliance and Privacy Concepts

## Learning Objectives

- Understand fundamental cybersecurity concepts.
- Learn cloud security responsibilities and models.
- Understand identity and access management.
- Explore Microsoft security technologies.
- Build foundational knowledge for Security Operations (SOC).
- Prepare for the Microsoft SC-900 certification.
