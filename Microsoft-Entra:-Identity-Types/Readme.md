# SC-900 - Microsoft Entra: Identity Types

## Microsoft Entra ID

Microsoft Entra ID is a cloud-based identity and access management service.

It helps organizations:

- Manage identities
- Authenticate users and workloads
- Control access to resources
- Enable Single Sign-On (SSO)

---

## Identity Types

### User Identities
Represent people such as employees, administrators and external users.

### Workload Identities
Represent applications, services and automation processes.

### Device Identities
Represent devices registered with or joined to Microsoft Entra ID.

### Agent Identities
Represent AI agents that access applications, data and services.

---

## Microsoft Entra Agent ID

Provides dedicated identity and access management for AI agents.

It helps control:

- What agents can access
- Which permissions they have
- How their activity is monitored

---

## Hybrid Identity

Connects on-premises identities with Microsoft Entra ID.

Microsoft Entra Cloud Sync can synchronize identities from on-premises Active Directory to the cloud.

---

## Microsoft Entra External ID

Provides secure access for users outside the organization.

Examples:

- Partners
- Contractors
- Customers

---

## Key Takeaways

- Microsoft Entra ID manages cloud identities and access.
- It supports user, workload, device and agent identities.
- Agent ID helps secure AI agents.
- Hybrid identity connects on-premises and cloud environments.
- External ID enables secure collaboration with external users.
